# إشعار مصدر corpus الخام: المكتبة الأخبارية

تتضمن مرحلة الجمع الخام ملفات نصية من مشروع **Ciyoku/ciyoku.github.io**، وهو مستودع مكتبة شيعية رقمية عربية مرخّص بترخيص MIT وفق ملف `LICENSE` في المستودع وقت المراجعة.

| الحقل | القيمة |
|---|---|
| المستودع | https://github.com/Ciyoku/ciyoku.github.io |
| الترخيص المعلن | MIT License |
| الملفات المجمعة | `الإحتجاج/book.txt`، `دلائل الإمامة/book.txt`، `تحف العقول/book.txt` |
| طريقة الاستعمال | جمع خام قبل مراجعة التكرار والتصنيف والنسبة؛ لا يُدمج مباشرة في واجهة القراءة |

يبقى اسم الكتاب ومؤلفه أو جامعه، ورابط المصدر، وبصمة SHA-256 لكل مقطع داخل بيانات مرحلة الجمع. لا يعالج هذا الإشعار صحة الأسانيد أو موثوقية اختلاف الطبعات.
