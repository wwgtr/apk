# بناء APK على GitHub

يحتوي المستودع على سير عمل GitHub Actions باسم **Build Android APK**. يبدأ تلقائيًا عند رفع تحديث إلى الفرع `main`، ويمكن تشغيله يدويًا من تبويب **Actions** في المستودع.

ينشئ السير العمل مشروع أندرويد الأصلي من إعداد Expo ثم يبني ملف APK موقّعًا بتوقيع التطوير، وهو قابل للتثبيت على جهاز أندرويد لأغراض الفحص. بعد نجاح التنفيذ، يُحمَّل الملف من صفحة التنفيذ ضمن قسم **Artifacts** باسم `TubeVault-APK`.

> هذا ملف فحص قابل للتثبيت. يتطلب ملف إصدار نهائي للنشر العام مفتاح توقيع إصدار ثابتًا يُحفظ في أسرار المستودع؛ لا يُضاف المفتاح إلى الشيفرة أو المستودع.
